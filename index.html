二、本机数据

游戏会在本机保存营地和攀登进度、登山日记及完成记录、教程状态、角色和画面操作设置、钩爪冷却等游戏状态，用于恢复旅程和保留偏好。游戏不会主动把这些数据上传至我们的服务器。我们没有自建账号、存档或统计服务器。

若使用路线或营地导入导出功能，只处理您主动选择或保存的文件，不自动上传。请妥善保管您自行导出的文件。

三、联网与第三方平台

H5 由托管平台通过网络向设备分发页面、模型、贴图、音乐和动作文件。因此首次加载、重新加载或缓存失效后仍可能需要联网；这不等于游戏具有联机玩法。本版本不接入广告 SDK、远程分析、登录、支付或设备广告标识采集功能，不主动向外部业务接口发送游戏存档或玩家信息。

TapTap 等分发、运行平台可能为账号、内容分发、实名及未成年人保护等平台服务独立处理信息，具体以实际运行平台展示的说明和规则为准。本政策不替代平台政策。

本隐私网页通过 GitHub Pages 托管，访问网页会向托管服务发出必要的网络请求。托管服务可能依其自身政策处理 IP 地址、访问时间及浏览器等请求信息。我们未在本页添加广告、统计脚本或追踪像素。

游戏不主动申请通讯录、定位、电话、相机或录音权限，不读取 IMEI、OAID 或 AndroidID。游戏进度在您清理本机站点或容器数据前保留；清理缓存和数据、卸载平台、切换浏览器或设备可能使进度丢失，且没有服务器备份可恢复。

我们不出售游戏存档。您通过邮箱反馈时，我们会使用您提供的邮箱、问题描述和自愿提供的附件处理请求，不要求提供身份证件、密码或广告密钥；反馈信息仅用于沟通处理，并在不再需要时删除，法律另有要求的除外。
