一、游戏功能与本机数据

游戏提供移动、攀登、钩爪、营地存档和登山日记等功能。我们没有自建账号注册、支付、聊天或云存档服务，不直接要求您提交姓名、身份证号码、手机号码、通讯录、相册、麦克风或地理位置。

数据用途及保存方式
营地、攀登进度、日记及完成记录用于恢复旅程及展示进度，保存在应用本机存储。
教程完成状态、画面和操作设置用于保留偏好，保存在本机。
钩爪冷却时间、广告奖励次数用于冷却计时和使用已获得的奖励，保存在本机；广告服务会处理奖励验证所需的交互信息。
隐私政策及广告同意记录用于记住您的选择和政策版本，保存在本机。

上述游戏存档不会由我们上传到自建服务器。卸载或清除数据可能丢失进度。若您主动导入、导出路线或营地布局，系统文件选择器仅访问您选择的文件；导出文件保存在您设备的下载目录，不会自动上传给我们。

二、自愿观看广告与第三方 SDK

广告不是进入游戏的前提。您点击“看广告 · 获得2次重置”，并在首次观看时另行同意广告说明后，才初始化和请求广告。完整观看且通过 SDK 奖励验证后，获得两次独立的钩爪冷却重置机会。跳过、关闭、播放失败或验证未通过不会发放奖励。

广告测试设备（可选）

设置中的“广告测试设备（OAID）”仅在您主动打开并点击“同意并读取”后，调用提供 HeyTap OpenID 服务的 OPPO、一加或真我设备系统服务，读取本机开放匿名广告标识 OAID 并显示。调用会向设备本机系统服务提供本应用包名及签名证书摘要以验证调用方。不会读取 IMEI 或 AndroidID，不生成替代设备标识。此功能参考 Android_CN_OAID 的 OPPO 协议实现，许可为 Mulan PSL v2，许可文本随安装包附带。

读取成功后仅保存“允许 OAID 测试”的开关，不在游戏存档中保存 OAID 原文；您点击“复制 OAID”时才复制到系统剪贴板，由您自行填入 Dirichlet 测试设备表单，游戏不会自动提交。授权后，TapADN 在您另行同意并主动请求广告时可以获取和使用 OAID，以匹配测试设备及进行广告投放、反作弊。若 SDK 已初始化，需要退出并重开应用来应用该开关。可在同一入口选择“关闭 OAID 测试”，或撤回隐私同意，停止 OAID 授权并退出。设备不支持或读取失败时不会自动开启该授权，不影响正常游戏。

三、权限及网络

联网及查看网络连接状态用于您主动请求的广告服务。游戏场景、角色和音乐随安装包提供。应用内会启动仅绑定设备本机回环地址（127.0.0.1）的资源服务，用于 WebView 读取随包资源，不向局域网提供服务。广告点击涉及下载或安装时，Android 仍会根据系统规则要求您确认；我们不会自动取得安装授权。

四、保存、共享与安全

本机游戏数据在您删除或卸载前保存；广告同意记录可撤回。我们不出售您的游戏存档，也没有将存档跨境上传的功能。广告 SDK 信息由服务提供方按其政策保存和处理；我们不会把本机存档主动提供给广告服务。您主动发送邮件反馈时，我们仅为沟通和处理请求使用您提供的邮箱及反馈内容，不要求您发送身份证件或广告密钥。

我们通过关闭不需要的采集项、限制本机资源服务地址及在取得同意后启用广告等方式减少信息处理。设备丢失、系统被修改或用户自行分享文件仍可能造成数据泄露，请妥善保护设备和导出的文件。

五、您的选择与权利

  • 查看政策：主界面“设置 → 隐私政策”，或游戏菜单“隐私与数据 → 隐私政策”。
  • 拒绝广告：不点击观看广告，或在首次广告说明中选择“暂不观看”，可继续攀登。
  • 撤回同意：设置中选择“撤回隐私同意”，确认后停止广告服务并退出；保留本机存档，再次打开会重新询问。撤回不影响撤回前基于同意已进行的处理。
  • 删除本机数据：设置中选择“删除本机游戏数据”，二次确认后清除游戏存档、教程记录、设置及奖励次数。已导出的文件需您在系统文件管理中另行删除。广告 SDK 自身缓存可通过 Android 应用信息中的“清除存储”或卸载删除。
  • 访问、更正、删除或投诉：可向 2490179393@qq.com 发送请求。涉及广告服务已处理的数据，也可通过供应方政策中的渠道提出。我们会在收到请求后核实范围并尽快答复；必要时协助转交相关服务方。

未满十四周岁的用户应与监护人共同阅读政策，并在监护人指导下使用。若监护人认为存在不当处理未成年人信息的情况，请通过下述邮箱联系我们处理。
